# 풍문투자증권

> 찌라시 하나로 시장을 흔드는 실시간 모의투자 게임

가상 회사 8곳에 대한 찌라시를 직접 써서 퍼뜨리고, 주가가 움직이는 틈을 타 사고팔아 돈을 버는 웹 게임입니다.
AI가 찌라시를 분석해 호재/악재, 그럴듯함, 파급력을 숫자로 바꾸고, 게임 엔진이 업종 성향과 랜덤을 섞어 주가를 움직입니다.

※ 등장하는 회사, 인물, 수치는 모두 가상입니다!!

## 프로젝트 목적

### 왜 만들었나
주식 시장에서는 "누가 그러던데" 수준의 찌라시가 실제로 주가를 움직입니다. 이 프로젝트는 그 과정을 **안전한 가상 시장에서 직접 겪어 보게** 하는 게임입니다.

- **풍문이 시장을 움직이는 원리 체험**: 어떤 소문이 먹히고, 어떤 소문이 역풍을 맞는지 플레이하며 익힙니다.
- **작전의 대가 이해**: 찌라시로 돈을 벌 수 있지만 금감원 조사, 과징금, 신뢰도 하락, 반대매매 같은 대가가 따릅니다. 시세조종이 왜 위험하고 불법인지 게임 규칙으로 보여 줍니다.
- **투자 기초 지식 학습**: 매입단가, 실현·평가손익, 수수료와 거래세, 상·하한가, 호가 단위, 공매도와 담보비율, 업종별 성향을 실제 제도에 가깝게 구현했습니다.

### 목표
- **자유 문장 → 게임 수치 변환**: 플레이어가 자유롭게 쓴 찌라시를 LLM이 정해진 JSON 으로 바꿉니다.
- **LLM은 판단, 코드는 결과**: 주가는 LLM이 직접 정하지 않습니다. LLM은 문장을 해석하고, 확률과 랜덤을 섞은 시뮬레이션 엔진이 결과를 정합니다. 그래서 LLM 응답이 조금 흔들려도 게임 밸런스가 깨지지 않습니다.
- **LLM의 다양한 역할**: 분석가(찌라시 채점), 코치(개선 조언), 심판(찌라시 대결 판정)으로 같은 모델을 프롬프트만 바꿔 씁니다.
- **실패에 강한 설계**: API 키가 없거나 호출이 실패해도 기본 분석기로 자동 전환되어 게임이 멈추지 않습니다.

## 사용 기술

| 구분 | 기술 | 쓰임 |
|---|---|---|
| 언어 | Python 3.11
| 웹 서버 | Flask
| LLM | OpenAI API (`gpt-4o-mini`, Chat Completions) | 찌라시 분석, 개선 조언, 대결 판정 |
| LLM 출력 제어 | JSON 모드 
| 프롬프트 기법 | 역할 지정, 채점 기준 명시, Few-shot 예시 4개, 업종 맥락 주입
| 동시성 | `threading.Lock` 
| 화면 | HTML · CSS · JavaScript 
| 차트 | Canvas 2D API 직접 구현 

### 구조

```
 플레이어 ─ 찌라시 입력 ─▶ Flask API ─▶ LLM (분석 JSON) ──┐
                                      └▶ 기본 분석기 (실패 시)┤
                                                            ▼
          화면 ◀── 0.5초 폴링 ◀── 게임 상태 ◀── 시장 엔진 (확률·랜덤·업종 성향)
                                                  ▲
                         NPC 투자자 · NPC 찌라시 · 시장 뉴스 · 금감원 · 대결
```

시장 엔진이 하는 일 (0.5초마다 한 번):
1. 시장 전체 움직임과 업종별 뉴스 효과 계산
2. 종목마다 NPC 주문 1~5건 체결 (찌라시로 생긴 매수/매도세 반영)
3. 상·하한가, 급등 호외, 금감원 조사, 반대매매, 급여·배당·대차 수수료 처리
4. NPC 찌라시, 시장 뉴스, 찌라시 대결 발생
5. 레벨·업적·파산 판정

## 사용 방법

### 설치와 실행

```bash
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 에 접속합니다.

- 처음 접속하면 직업 선택 창이 뜹니다. 직업을 고르면 게임이 시작됩니다.
- `templates/index.html`을 직접 열면 화면 틀만 보입니다. 반드시 `python app.py`로 서버를 켠 뒤 주소로 접속하세요.

### AI 분석 켜기 (선택)

OpenAI API 키가 있으면 AI가 찌라시를 분석하고 찌라시 대결을 판정합니다. 키가 없어도 기본 분석기로 모든 기능이 동작합니다.

1. `.env.example`을 복사해 `.env`로 이름을 바꿉니다.
2. `OPENAI_API_KEY=sk-...` 형태로 키를 넣습니다.
3. 서버를 다시 켜면 터미널에 `AI 분석 켜짐 (모델 gpt-4o-mini, 키 위치: ...)`이 표시됩니다.

키는 이 폴더뿐 아니라 위쪽 폴더의 `.env`까지 찾아봅니다. `sk-`로 시작하지 않는 자리표시자 값은 무시합니다.
모델을 바꾸려면 `.env`에 `OPENAI_MODEL=모델이름`을 추가하세요.

### 한 판 플레이 흐름

1. **직업 고르기**: 회사원(월급), 백수(팔로워↑), 대학생, 공무원 중 하나를 고릅니다.
2. **종목 살피기**: 왼쪽 순위와 실시간 검색어, 차트 아래 업종 설명을 봅니다.
3. **포지션 잡기**: 오를 것 같으면 매수, 내릴 것 같으면 공매도합니다.
4. **찌라시 뿌리기**: 내 포지션에 유리한 소문을 씁니다. 구체적인 숫자와 출처를 넣고, 업종에 맞는 이슈를 고르세요. 아이템으로 성공 확률을 올릴 수도 있습니다.
5. **차익 실현**: 주가가 움직이면 매도(또는 상환)해서 수익을 확정합니다. 금감원 조사가 터지기 전에 빠지는 것도 전략입니다.
6. **대결 대응**: NPC가 대결을 걸어오면 반박 찌라시로 맞섭니다.
7. **성장**: 자산이 늘면 레벨이 오르고 새 직업(유튜버, 국회의원, 대통령…)과 기업 인수가 열립니다.
8. **결과 확인**: "내 자산" 메뉴에서 돈이 어디서 들어오고 나갔는지 전부 확인합니다.

## 게임 방법

### 1. 찌라시 뿌리기
종목을 고르고 소문을 써서 퍼뜨립니다. 결과는 세 가지 숫자로 정해집니다.

| 항목 | 의미 |
|---|---|
| 호재/악재 | 주가에 좋은 소식인지 나쁜 소식인지 (−1 ~ +1) |
| 그럴듯함 | 구체적인 숫자·시점·출처가 있고 업종에 맞을수록 높음 |
| 파급력 | 사실이라면 주가가 얼마나 움직일지 |

- 시장이 믿으면 소문 방향으로 움직이고, 안 믿으면 반대로 역풍을 맞습니다.
- 매번 "AI 코치"가 찌라시를 더 그럴듯하게 만드는 조언을 줍니다.
- 신뢰도가 높을수록, 팔로워가 많을수록 잘 먹힙니다.
- 파급력이 큰 찌라시일수록 금감원 조사 위험도 커집니다. 조사는 8~20초 뒤에 터집니다.

### 2. 매매
주문창은 **매수 · 매도 · 공매도 · 상환** 네 탭입니다.

- 매수·공매도의 10/25/50%/최대 버튼은 지금 현금으로 가능한 최대 수량 기준입니다.
- 매도·상환의 % 버튼은 보유(공매도) 수량 기준입니다.
- 주문 전에 수수료·세금, 예상 실현손익, 반대매매 가격을 미리 보여 줍니다.

### 3. 공매도
주식을 빌려 먼저 팔고, 나중에 되사서 갚습니다. 주가가 떨어지면 이익입니다.

- 판 돈은 담보로 묶이고, 현금에서 증거금 40%가 추가로 묶입니다.
- 1분마다 대차 수수료(빌린 주식 가치의 0.1%)가 나갑니다.
- 담보가 상환 비용의 115% 밑으로 떨어지면 반대매매(강제 상환)됩니다.
- 하한가에서는 공매도할 수 없습니다.

### 4. 찌라시 대결
35~65초마다 NPC 작전세력이 종목 하나에 소문을 퍼뜨리며 대결을 걸어옵니다.

1. 20초 안에 판돈(현금의 10/25/50%)을 걸고 수락하거나 피합니다.
2. 45초 안에 반대 방향의 반박 찌라시를 씁니다.
3. AI 심판이 판정합니다. 이기면 판돈 두 배, 지면 판돈을 잃고 주가도 상대 쪽으로 움직입니다.

### 5. 레벨과 직업
총자산에 따라 레벨이 오르고, 레벨마다 혜택과 새 직업이 열립니다. 한 번 연 혜택은 자산이 줄어도 유지됩니다.

| 레벨 | 총자산 | 혜택 | 열리는 직업 |
|---|---|---|---|
| 1 개미 | 시작 (1,000만) | 기본 | 회사원, 백수, 대학생, 공무원 |
| 2 투자 동호회장 | 1,500만 | 암시장 아이템 10% 할인 | |
| 3 전업 투자자 | 3,000만 | 매매 수수료 면제, 대차 수수료 절반 | 증권사 애널리스트, 주식 유튜버 |
| 4 슈퍼개미 | 7,000만 | 금감원 과징금 30% 감면 | 경제부 기자, 전문투자자 |
| 5 큰손 | 1.5억 | 기업 경영권 인수 해금 | 사모펀드 사장 |
| 6 사모펀드 대표 | 5억 | 인수 기업 배당 2배 | 재벌 3세, 국회의원 |
| 7 재벌 총수 | 20억 | 인수 기업 소문이 '공시'로 통함 | 대통령 |
| 8 회장님 | 100억 | 명예의 전당 (엔딩) | |

직업마다 수입, 장점, 약점이 다릅니다. 특히 아래 두 직업은 고유 능력이 있습니다.

- **국회의원**: 시장 뉴스를 10초 먼저 듣습니다. 금감원에 적발되면 의원직을 잃습니다.
- **대통령**: 정책(금리 인하, 보조금 축소 등)을 직접 발표해 시장을 움직입니다. 적발되면 탄핵입니다.

레벨이 오를수록 난이도도 올라갑니다 (쉬움 → 보통 → 어려움 → 지옥).
찌라시 성공률이 내려가고, 조사 위험과 역풍 크기, 대결 상대의 실력이 올라갑니다.

### 6. 기업 인수 (Lv.5부터)
지분 30%를 경영권 프리미엄 20%를 얹어 사들입니다.

- 인수한 기업은 1분마다 배당을 줍니다.
- 매각은 블록딜이라 5% 할인됩니다.
- 인수한 회사에 대해 찌라시를 뿌리면 내부자 거래로 의심받습니다.

### 7. 파산
총자산이 30만 원 아래로 떨어지면 반대매매로 계좌가 정리되고 게임 오버입니다. "새 계좌"로 다시 시작할 수 있습니다.

| 내 자산 | 총자산 계산식, 순이익 구성, 종목별 손익, 공매도 포지션, 계좌 입출금 내역, 찌라시 수익 기록 |
| 기업 인수 | 보유 기업, 인수 가능 기업과 비용 |
| 레벨 · 업적 | 레벨 로드맵, 업적 32종 |
| 프로필 | 닉네임, 직업, 팔로워, 자산·팔로워 추이, 게시글(좋아요·댓글) |

### 자산 계산 방식

```
총자산 = 현금 + 주식 평가금액 + 기업 지분 가치 + 대결 판돈(묶임) + 공매도 순자산
순이익 = 총자산 − 원금 1,000만 원
       = 주식 평가손익 + 주식 실현손익 + 지분 평가손익 + 매각 차익
         + 공매도 평가·실현손익 − 대차 수수료
         + 급여·배당 + 대결 손익 − 아이템 − 과징금
```

- 매입단가 = 매입원가(매수 수수료 포함) ÷ 보유 수량
- 실현손익 = 실수령액(매도 금액 − 수수료 − 거래세) − 판 만큼의 매입원가
- 현금이 움직이는 모든 경우가 입출금 내역에 잔액과 함께 기록됩니다.
- "내 자산" 화면 오른쪽 위에 검산 결과(입출금 잔액 = 현금, 순이익 = 구성 합계)가 표시됩니다.

## 문제 해결

| 증상 | 해결 |
